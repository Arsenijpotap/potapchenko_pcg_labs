Лабораторная работа № 3
Тема: морфологическая обработка и низкочастотные (сглаживающие) фильтры

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. В этой папке запустите локальный сервер командой:
   python -m http.server 8000
3. Откройте в браузере http://localhost:8000
4. Используйте встроенный пример или нажмите «Загрузить изображение».
5. Выберите метод и операцию, настройте параметры и нажмите «Применить».

РЕАЛИЗОВАННЫЕ ФУНКЦИИ
1. Низкочастотные фильтры:
   - средний фильтр;
   - фильтр Гаусса с разделяемой свёрткой: проход по строкам, затем по столбцам;
   - медианный фильтр.
2. Морфологические операции:
   - эрозия и дилатация;
   - открытие и закрытие;
   - морфологический градиент;
   - Top-Hat и Black-Hat;
   - структурный элемент: квадрат, крест или ромб.
3. Дополнительные алгоритмы:
   - CLAHE — локальное выравнивание гистограммы с ограничением контраста;
   - Кэнни — поиск границ с подавлением немаксимумов и двойным порогом с отслеживанием границ;
   - адаптивная бинаризация на основе интегрального изображения.
4. Обработка границ: Clamp и Reflect.
5. Гистограммы яркости до и после обработки.
6. Загрузка изображений, сброс результата, сравнение исходного и обработанного изображения, сохранение PNG.
7. Вычисления выполняются в Web Worker, чтобы не блокировать интерфейс во время обработки.
8. Изображения перед обработкой переводятся в оттенки серого. Очень большие изображения автоматически уменьшаются до разумного размера для браузерной обработки.

СТРУКТУРА
- index.html — интерфейс.
- style.css — оформление.
- js/main.js — управление приложением, загрузка, сохранение, гистограммы и Web Worker.
- js/ui.js — доступные методы и обновление настроек.
- js/pixel-utils.js — работа с пикселями и краями изображения.
- js/smoothing.js — сглаживающие фильтры.
- js/morphology.js — морфологические операции.
- js/advanced.js — CLAHE, Кэнни, адаптивная бинаризация и гистограмма.
- js/processing-worker.js — обработка в фоновом потоке.
- js/demo.js — встроенный демонстрационный пример.

ПРИМЕЧАНИЕ
Реализация использует JavaScript и Canvas ImageData, без библиотек фильтрации. Если в задании требуется именно прямой доступ к памяти через unsafe/указатели/LockBits, браузерная реализация сама по себе это требование не заменяет. CLAHE реализован по небольшим плиткам; для более качественного устранения границ между плитками может понадобиться билинейная интерполяция между соседними LUT.
